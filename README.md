# Surveys and Forms / Static HTML

[Leia em português](./README.pt-BR.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE) ![Free](https://img.shields.io/badge/price-free-brightgreen)

A form builder with both of its sides, built with plain HTML, vanilla JavaScript and Tailwind CSS v4: the public form a respondent actually fills in, and the workspace where it is designed and read. Respondents get one question at a time, a progress bar, inline validation and conditional logic that genuinely decides which question comes next and which ones never appear. Authors get a drag-to-reorder builder covering ten question types, tabs for logic, appearance and sharing, a summary that picks the right chart for each question type — including an NPS gauge and a matrix heatmap — individual responses in a drawer, and a CSV export written in the browser. NPS, completion rate and average time are computed, never stored. Six forms and a hundred and twenty-six responses ship as seed data, generated by a deterministic PRNG that walks the same logic engine the public form uses, persisted to `localStorage`, so nothing needs a backend.

Live preview: https://template.dev.br/preview/survey-html/

## Pages included

14 screens, covering the public site and the authenticated area:

- Home: hero, the question types in cards, how it works in three steps, ready-made models, testimonials, plans and an FAQ
- Models: gallery by objective (NPS, satisfaction, event signup, market research, internal feedback) with a preview of the questions
- Fill: the real public form — one question at a time, progress bar, validation and conditional logic, with back and next
- Thank you: the configured closing message plus a recap of what was answered
- Contact: validated contact form
- Login and Register: standalone auth screens
- Dashboard: responses this month, completion rate, average time, NPS, a responses-per-day chart, most answered forms and the latest responses
- Forms: table with search and a status filter, plus duplicate, close and copy public link
- Builder: Questions (drag to reorder, with a side panel editing the selected question and a live preview), Logic, Appearance and Share tabs
- Responses: Summary with one chart per question type, and Individual with a table and a full-response drawer, plus CSV export
- Model library: start a new form from a model
- Contacts: who answered, with source, tags and score
- Settings: profile, organisation, per-response notifications, theme and language
- Not found: 404 page

## Tech stack

- Static HTML pages — one file per screen, no framework
- Tailwind CSS v4 compiled by the Tailwind CLI into `assets/css/tailwind.css`
- Vanilla JavaScript in `assets/js/`, loaded as classic scripts — no bundler at runtime
- State kept in `localStorage`, mirroring the store shape of the other stacks
- Client-side i18n from `assets/i18n/*.json` (en, es, pt-BR)
- ApexCharts 3.49 from a CDN
- Web app manifest and service worker for the installable PWA

## Getting started

```bash
npm install
npm run build
npm run dev
```

`npm run build` compiles the stylesheet; `npm run dev` serves the folder. Any static file server works — the pages have no build-time templating. Demo credentials:

- `pesquisa@sondagem.com` / `demo123`

Any non-empty email and password logs in; the pair above is the account suggested on the login screen and the one the seed data belongs to.

## Build for production

```bash
npm run build
```

Recompiles `assets/css/tailwind.css`. Deploy the folder as-is to any static host.

## Theming and customization

Tailwind CSS v4 is configured in CSS, not in a JavaScript config file. The stylesheet imports Tailwind, declares the dark variant and defines the design tokens inside `@theme`: the Outfit font family, extra breakpoints and the brand color ramp (`--color-brand-25` through `--color-brand-950`). Semantic surface tokens use the `--tx-` prefix. Dark mode is a class on the root element, toggled at runtime and persisted. The accent colour and cover of each form are data, so restyling a survey is a data change rather than a template change.

## Internationalization

Three locales ship with the template: English, Spanish and Brazilian Portuguese. The browser language is detected on first load and the header switcher persists the choice. Dates, numbers and durations are formatted per locale.
